# План тестирования методом «Черного ящика» (Black-box Testing)

## 1. Цель
Верификация корректности работы алгоритмов обработки временных рядов непрерывно-дискретных данных информационной системы контроля состояния техногенного объекта (Вариант №70).

## 2. Методология
Используется техника тестирования «черного ящика»: проверка соответствия выходных данных (графики фазовых координат α(µ), µ(t)) входным данным (координаты Z контрольных точек) без анализа внутренней реализации кода.

## 3. Набор тестовых данных (Fixtures)
Все тестовые базы данных находятся в директории [`../../database/fixtures`](../../database/fixtures).

| ID | Файл БД | Сценарий имитации | Ожидаемый результат (Output) | Статус |
|----|---------|-------------------|------------------------------|--------|
| TC-01 | `test_rest_state.sqlite` | Состояние покоя | Координаты Z неизменны во всех циклах. Прямая горизонтальная линия. | ✅ Passed |
| TC-02 | `test_jump_deformation.sqlite` | Скачкообразная деформация (Авария) | Резкий разрыв графика µ(t). Система фиксирует переход в аварийное состояние. | ✅ Passed |
| TC-03 | `test_cyclic_movement.sqlite` | Циклическое колебание | Синусоидальная траектория на фазовой плоскости α(µ). Стабильный период. | ✅ Passed |
| TC-04 | `test_uniform_motion.sqlite` | Равномерное поступательное движение | График µ(t) — прямая линия с постоянным наклоном. Отсутствие ложных тревог. | ✅ Passed |

## 4. Процедура тестирования
1. Запустить приложение `curseuch.exe`.
2. На вкладке **«Данные»** нажать **«Выбрать БД»**.
3. Указать путь к одному из файлов в папке `database/fixtures/`.
4. Нажать **«Открыть таблицу»**.
5. Перейти на вкладку **«Первый уровень декомпозиции»**.
6. Визуально сверить построенные графики с описанием сценария в таблице выше.
7. Повторить для остальных уровней декомпозиции (II, III, IV), распределяя точки по блокам согласно варианту №70.

## 5. Критерии приемки
*   Погрешность расчетов не превышает заданную точность измерений E (см. таблицу «Значения» в БД).
*   При наличии скачка (>E) система обязана вывести предупреждение о переходе на следующий уровень анализа.
